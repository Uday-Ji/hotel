# Hotel Booking System

Enterprise-grade hotel booking and management system built with React, TypeScript, and Redux Toolkit.

## Features

- 🏨 Complete hotel management
- 📅 Booking and allocation system
- 💰 Rate and promotion management
- 📊 Comprehensive reporting
- 🚗 Transfer/transport module
- 👥 User and role management
- 🏢 Multi-tenant architecture
- 📦 Package management
- 🚗 Car rental system
- 👁️ Sightseeing tours
- 📈 Market analysis

## Tech Stack

- React 18
- TypeScript (Strict Mode)
- Redux Toolkit
- Material-UI v5
- React Router v6
- React Hook Form + Zod
- Axios

## Getting Started
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure
```
src/
├── config/          # Configuration files
├── store/           # Redux store and slices
├── routes/          # Route configuration
├── layouts/         # Layout components
├── pages/           # Page components
├── services/        # API services
├── types/           # TypeScript types
├── utils/           # Utility functions
└── styles/          # Global styles
```

## Environment Variables

Copy `.env.example` to `.env` and update the values:

- `VITE_COMPANY_CODE`: Your company identifier
- `VITE_API_BASE_URL`: Backend API URL
